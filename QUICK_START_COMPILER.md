# ⚡ Quick Start - Compiler in Exams

## 🎯 For Students

### How to Use the Compiler During Exams:

1. **Start your exam** from the dashboard
2. When you see a **coding question**, the compiler loads automatically
3. **Choose your language** from the dropdown (Python, Java, C, C++, C#, JavaScript, PHP)
4. **Write your code** in the editor (it auto-saves!)
5. **Add test input** (if needed) in the input box below the code
6. **Click "Run Code"** to test your solution
7. **View the output** on the right side
8. **Fix any errors** and test again
9. Your code is automatically **saved as your exam answer**

### Tips:
- ✅ Click **"Template"** to get starter code
- ✅ Use **Tab key** for proper indentation
- ✅ Test your code **multiple times** before submitting
- ✅ Code **auto-saves** - you won't lose your work!
- ✅ Check **execution time** to optimize your solution
- ✅ Read **error messages** carefully for debugging hints

## 📚 For Trainers/Admins

### How to Create Coding Questions:

1. Go to **Admin Panel** → **Assessments**
2. **Create or Edit** an exam
3. Click **"Add Question"**
4. Select **Type: "Code"** (or "Coding")
5. Write your question text
6. (Optional) Add **expected output** for auto-grading
7. (Optional) Add **test cases** in JSON format
8. **Save** the question

### Students will automatically see:
- Full code editor
- Language selector
- Run & test functionality
- Input/output sections

## 🔧 Quick Troubleshooting

### Problem: "Compiler not available" error
**Solution:** Install the required compiler (Java JDK, GCC, .NET SDK, etc.) and add to system PATH

### Problem: Code doesn't save
**Solution:** Check browser's localStorage settings, ensure cookies are enabled

### Problem: Timeout errors
**Solution:** Optimize code to run faster (10-15 second limit)

### Problem: Compilation errors
**Solution:** Click "Template" to see correct syntax, check for typos
